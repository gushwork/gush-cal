# Run E2E — Reference

## Trigger discovery

Search in order; stop at first match.

| Source | Look for |
|--------|----------|
| `package.json` → `scripts` | `test:e2e`, `e2e`, `e2e:ci`, `cy:run`, `playwright test` |
| Root configs | `playwright.config.ts`, `playwright.*.config.ts`, `cypress.config.*` |
| CI | `.github/workflows/*` — `playwright test`, `cypress run` |
| Monorepo | Per-package `package.json` when invoked from subdir |

**Multiple configs:** prefer dedicated E2E config over visual-only (e.g. `playwright.config.ts` over `playwright.visual.config.ts`). If only visual config exists, note gap — suggest `setup-e2e`.

**Fallback command construction:**

```bash
# Playwright — config present, no script
npx playwright test --config=<config>

# Playwright — tests/e2e/ dir, default config missing
npx playwright test tests/e2e

# Cypress
npx cypress run
```

## Server startup

Many Next/React apps need a running server. Pattern:

```bash
PORT="${PORT:-4000}"
export PLAYWRIGHT_BASE_URL="${PLAYWRIGHT_BASE_URL:-http://localhost:${PORT}}"

# Option A — project script
START_SERVER=1 npm run test:visual   # if wrapper exists

# Option B — manual
npm run build && npm run start &
# wait for HTTP 200 on / or /login
npm run test:e2e
# kill server on exit
```

Reuse project wrappers (`scripts/visual-audit.sh`) when they already handle build/start/wait/cleanup.

Document in report: `PORT`, `PLAYWRIGHT_BASE_URL`, auth storage state path.

## Report notes

- **Flaky vs failed:** retries that eventually pass → Flaky section, not Failures
- **Likely cause:** one line — selector drift, timing, missing seed data, env var, auth expiry
- **Coverage gaps:** list `app/` routes or API handlers with no matching `tests/e2e/*` spec — ponytail quick grep, not full exploration
- **Exit code non-zero with 0 failures:** note runner config issue or setup error
- **Large output:** write log file, link path in report; don't paste 500+ lines in chat
- **Map failures** to spec file + branch name when filename encodes it (`booking.spec.ts` → booking branch)
